# Проектная работа «Stellar Burger»

Веб-приложение для создания и заказа бургеров онлайн. Реализован drag-and-drop конструктор, авторизация, просмотр истории заказов, защищённые маршруты и интеграция с API.

## Ключевые технологии и стек
- **React** — построение пользовательского интерфейса
- **Redux Toolkit** — современное управление состоянием приложения
- **TypeScript** — строгая типизация компонентов, утилит и бизнес-логики
- **React Router** — маршрутизация, защищённые и публичные маршруты
- **Cypress** — функциональное и end-to-end тестирование
- **Jest** — юнит-тесты редьюсеров и бизнес-логики
- **Drag-and-drop** — реализация конструктора бургеров
- **API** — интеграция с сервером для получения ингредиентов и оформления заказов
- **Cookie** — хранение токенов для авторизации
- **Webpack** — сборка и оптимизация проекта
- **ESLint, Prettier** — поддержка единого стиля кода и качества

## Основной функционал
- Конструктор бургеров с drag-and-drop
- Авторизация и регистрация пользователя
- Защищённые маршруты (личный кабинет, история заказов)
- Просмотр ленты заказов в реальном времени
- Детализация ингредиентов и заказов
- Адаптивная верстка

## Установка и запуск проекта
1. Установите зависимости:
   ```sh
   npm install
   ```
2. Запустите проект:
   ```sh
   npm start
   ```
3. Откройте [http://localhost:3000](http://localhost:3000) в браузере

## Тестирование
- Запуск unit-тестов:
  ```sh
  npm test
  ```
- Запуск Cypress-тестов:
  ```sh
  npx cypress open
  ```
